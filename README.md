# 通信大组地图

面向长期跟踪的精选研究地图：学校 → 大组 → 研究主线 → 有来源的进展日志。

范围是内地39所985、北邮、西电，以及香港大学、香港中文大学、香港科技大学、香港城市大学、香港理工大学，以通信工程为主。未入选不代表团队质量低；首版是可校正的编辑精选，不是学校或个人排名。

网站采用静态 HTML/CSS/JavaScript，可直接部署 GitHub Pages，无需服务器或API密钥。

## 选什么、看什么

入选同时考察持续团队、可辨识的研究路线、可核查的影响力及近期活跃。每组先用一句话回答“值得关注什么”，详情再解释过去做什么、近期做什么、下一步值得验证的问题，并链接学校/团队官网及原始论文。

“下一步观察”是根据公开证据提出的跟踪问题，并非教授已宣布的研究计划。不把论文数量、头衔、机构规模直接等同于研究质量，不按合作关系把多个独立实验室混成一个组。覆盖审查及暂缓原因见 `data/coverage.json` 与 `research/`。

## 两层更新

- GitHub Actions 每周三/六北京时间约08:17从 arXiv API抓候选。版本合并、精确姓名匹配、通信关键词只是初筛，候选始终标 pending，不自动写进组日志。
- 定时研究任务在周三/六随后检查候选、官网及原始成果，核对单位/团队归属，筛掉增量很小的论文，将真正有信息量的变化写成短日志并提交发布。原始候选没有红点。

GitHub及定时任务可能排队；采集失败保留旧数据，页面标注状态。arXiv覆盖有盲区，官网、开放代码、实验平台与重大项目消息同样可作为补充证据。新的采集成功并不代表新的编辑审阅。

首次发布建立基线，不伪造新增动态。本轮编辑有变化会显示更新标记；本设备未读以每组revision比较，读过详情后消除本设备红点。首次访问从首版基线开始，后来新增的真实编辑版本仍能提示。已读状态只保存在当前浏览器，跨设备不会同步。

## 本地运行与验证

```bash
python3 -m http.server 8000
python3 -m unittest discover -s tests -v
node --check app.js
python3 scripts/build_site.py
```

打开 `http://localhost:8000`。`dist/`为部署产物，打包不包含研究草稿与测试。

日常维护请遵循 [AGENTS.md](AGENTS.md)。采集器、schema及审阅规则见 [更新流程](docs/UPDATES.md)。

## 已考察的开源方案

- [arxiv-sanity-lite](https://github.com/karpathy/arxiv-sanity-lite)：适合按论文标签推荐，依赖服务端与全文候选库；不负责学校、团队归属核验及研究路线编辑。
- [daily-arXiv-ai-enhanced](https://github.com/dw-dengwei/daily-arXiv-ai-enhanced)：可用 Actions + Pages 做论文摘要，但默认是论文流并需模型密钥，不直接解决本项目的精选大组与误归属问题。
- [people-map](https://github.com/poloclub/people-map)：展示研究者文本相似关系，适合探索，不是按地理位置维护大组日志。

本项目采用 Actions + Pages 的成熟部署方式，自行实现轻量数据模型和编辑流程；未复制上述项目代码。地图仅绘公开海陆轮廓及经纬位置，不绘行政界，数据来源与许可见 assets 内说明。
